# 可写进简历的成果

**零售邮件营销增量评估｜Python、统计推断、增量评估**

- 基于 64,000 条公开三组随机实验记录，按全部分配客户评估两周购买与每客消费，完成数据质量、分组人数及实验前特征诊断，并以独立 SQLite 汇总对账。
- 使用 Newcombe 比例差区间、Welch 均值差及 Bonferroni 校正，估计男装/女装邮件购买增量为 0.681/0.311 个百分点；男装邮件每客消费增加 0.770 美元，97.5% 区间为 [0.444, 1.095]。
- 交付可复现代码、结果表、置信区间图和实验复盘报告，形成内容配置、营销预算、客户体验与分层触达的运营试点方案。

面试边界：公开历史实验复盘，未亲自实施线上实验；结果不等于本人提升公司转化率或已实现利润。分析方案为回顾性，异质性分析尚未完成。
